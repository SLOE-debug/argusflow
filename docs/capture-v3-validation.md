# 屏幕采集 v3 实施与验证记录

2026-09-09，本机 Windows 原生 DXGI 测试。所有结果均来自当前代码，不进行浏览器自动化。

## 已接入

- `argusflow-core::capture` 承载帧、坐标、时间及来源契约；`argusflow-capture` 提供精确差分、不可变块快照、有序/最新游标和共享窗口源。
- Windows 的 DXGI 与 WGC 共用三槽区域读回；Map 使用 DO_NOT_WAIT，WGC 不再占住主机线程等待 GPU。DXGI 脏区与移动目的地读取当前最终像素。
- 录制采用独立屏幕索引、完整检查点和区域 PNG，两个编码线程按序发布。失败自动停止 Hook 并保存有效前缀。停止排空已提交 GPU 槽及编码队列。
- OCR 使用共享窗口会话与变化历史；ROI 扩展 16px 并纳入相交文本框，提交前复验拓扑和新变化。
- v3 读取、逐帧回看、来源切换、变化区域展示、事件关联、隐私处理和受限帧/区域 IPC 已接入。

## 确定性验证

`cargo test -p argusflow-capture -p argusflow-recorder -p argusflow-vision -p argusflow-windows --lib --quiet`

最近结果：Capture 7 通过；Recorder 39 通过、2 个真实全局 Hook 测试忽略；Vision 39 通过；Windows 27 通过。录制旧稳定采样测试随被替代实现删除，不能将新旧测试数量直接相加。

- 100/50/33ms 时间序列，完整基准加 `notepadd` 的八次不同细笔画变化，包含连续两个 d；验证按下/释放关联、落盘后逆序重建逐像素一致。
- 共享订阅只创建一次原生源；慢消费者跳过中间帧后，变回原颜色的区域仍保持脏状态。
- 无效保留通道不触发变化；单像素、边缘块、负坐标、精确候选和旋转有测试覆盖。
- 隐私修改重建后继依赖，确认原区域文件已删除且后继真实像素未被意外改变。

前端相关 8 个测试文件、25 项测试通过。`npx tsc -b` 与 Tauri `cargo check` 通过；IPC 权限测试 2 项通过。

## 原生性能探针

执行 `cargo run --release -p argusflow-windows --example screen_stream_bench -- WIDTH HEIGHT`。自有无激活窗口每 50ms 改变 64×16 区域，连续 108 次；只在内存检查像素，不保存桌面图像。探针测量冻结时间与 DXGI LastPresentTime 的差值，使用与录制一致的 0.5ms 高精度等待。窗口尺寸不是修改显示器输出模式；采集仍覆盖机器的实际桌面。

| 自有窗口 | 前八次 | 全序列 | 累计呈现缺口 | 读回总字节 | 差分总耗时 | 呈现至冻结 P95 |
| --- | --- | --- | --- | --- | --- | --- |
| 1920×1080 | 8/8 | 108/108 | 0 | 29,227,196 | 25,728µs | 5,719µs |
| 2560×1440 | 8/8 | 108/108 | 0 | 16,897,216 | 25,048µs | 6,420µs |
| 3840×2160 | 未运行 | 未运行 | 未测 | 未测 | 未测 | 未测 |

4K 窗口超过本机主屏范围，fixture 返回 E_INVALIDARG；没有调整系统显示模式，也不把较小窗口结果推算成 4K 达标。总读回包含完整桌面基准及其它实际桌面变化，所以不同窗口的总字节不能作为同分辨率带宽对照。此探针没有 PNG 归档负载，不代表完整录制端到端吞吐。

## 尚未完成的验收与边界

- 4K 原生输出、带 PNG 归档负载的队列峰值和长期性能验收仍需完成。
- DXGI 已由共享桌面主机推进并跨录制保持存活；WGC 通过共享窗口源复用。两个目标的生命周期通知仍需统一完善。
- 旧同步窗口截图接口仍保留供原有独立截图探针使用，尚未全部移除。
- 桌面失效撤销共享流并重建，已有有序订阅停止；窗口失效的自动恢复与统一生命周期事件仍未完整实现。
- 停止订阅通过共享主机排空屏障取得各来源截止版本，归档仅提交该版本之前的变化；应用退出显式关闭共享线程。
- 桌面历史总预算为 128MiB，来源增多时重新分配并淘汰各来源历史，落后有序消费者明确报告缺口。
- 输入关联仍使用与 QPC 起点相邻采样的 Win32 毫秒事件时钟，不是每个 Hook 事件直接记录 QPC。
- v3 事件证据中仍保留旧单图字段；未提供 v2 转换或双写。

以上边界意味着当前实现不能宣称整份计划已经完成。
