# 工作流画布

画布主场景由单个 Canvas 2D 表面绘制。网格、节点、容器、起止标记、连线、框选和临时连线均不创建场景 DOM；菜单、搜索、工具栏和辅助语义保留 DOM。画布不显示缩略图。

## 坐标与编辑归属

- `EditorTab.viewport` 始终将根场景坐标映射到画布 CSS 像素，`studio.view` 只更新相机。
- `EditorTab.scope` 仅表示当前编辑作用域；`studio.select(ids, scope)` 同步选择和属性面板归属，不移动相机。
- 作用域局部变换与根相机组合后用于绘制和命中。while、for_each、if、switch、block 的内部流程始终属于同一个场景，远景省略文字不改变布局。
- 添加和粘贴接受显式作用域。浮层保存打开时的作用域及局部坐标，等待期间不根据当前选择重新解释落点。
- 同层节点支持多选、拖动、排列、剪贴板和连线；跨层操作不改变节点归属或生成连线。

## 操作

滚轮围绕指针缩放；触控板捏合也使用指针锚点。中键、空格加拖动或平移工具可无限平移。双击容器或选中后按 Enter 聚焦子流程，面包屑聚焦祖先，显示全部定位根流程。

直接点击子节点即可编辑。拖动使用连续局部坐标的临时预览，不强制吸附背景网格；指针移动直接通知绘图表面，按帧合并，不触发 React 重渲染。松手只提交一次历史记录，Escape、指针取消和窗口失焦丢弃预览。若提交后子图边界变化导致祖先布局重新定位，相机会补偿该作用域的位移，使节点落点保持稳定。

拖动接近同层节点的左/右边、上/下边或中心线时，显示紫色对齐参考线并轻度吸附。开始、结束和容器也参与对齐，多选以整体边界吸附并保持内部间距；父子层级不互相吸附。吸附与脱离共用 5 个 CSS 像素范围，每次都从鼠标按下位置计算原始位移，不累计吸附修正，也不增加脱离门槛。按住 Alt 立即暂停吸附，松开恢复；辅助线在松手、取消和切换文档后消失。参考对象索引在拖动开始时建立，参考线随节点预览按帧绘制，线宽和标记尺寸不随缩放变化。交互参考 [WinForms SnapLines](https://learn.microsoft.com/en-us/dotnet/desktop/winforms/controls/walkthrough-arranging-controls-on-windows-forms-using-snaplines)，阈值为当前画布的独立设计参数。

端口和连线使用屏幕像素容差命中，背景命中返回最深的可编辑作用域。空子流程内双击可添加首个节点。运行期间禁止修改流程，但仍可选择和浏览。

新建工作流及容器的每个子作用域默认有开始、结束卡片及一条显式直连。卡片可选择、拖动、框选、删除和复制，固定布局键为 `$start:<scope>`、`$end:<scope>`，不增加执行动作。每个作用域都必须具备两张卡片才能保存；缺失时保留内存草稿，问题面板可定位对应作用域，不覆盖磁盘。断线、孤立节点、多出口和汇合可保存。粘贴已有同类标记时保留原位置，复制容器重建子作用域及其边身份。

悬停节点显示四边中点，离开节点与操作点区域后隐藏。普通节点和开始可以出线，结束与 Return、Fail、Break、Continue 只接收入线。拖到节点主体自动选边，命中端口使用指定边，连接完成保存两端边位。独立连线始终追加，不覆盖已有出口；拒绝重复源目标、自环、图回环和跨作用域连接。

点击线路独立选中，与节点选择互斥。选中线路显示两端操作点，端点命中优先于节点端口，可拖动来源或目标，固定另一端并实时避障预览；成功改接保留边 ID，仅提交一次历史。Delete 和线路右键菜单删除指定边。新线在空白松手打开节点搜索，创建节点并连接；已有线在空白或无效落点松手恢复原连接。Escape、指针取消、失焦与文档切换均取消预览。

文件、图及剪贴板直接使用当前契约，不设置格式版本号。`scope.edges` 保存稳定 ID、来源和目标；端点使用 `start`、`end` 或 `node` 身份，`editor.edges` 保存 `source`、`target` 的 `top/right/bottom/left` 边位。常规添加只在确定的线性结束线上插入；线路菜单按指定边 ID 拆线。删除单入单出节点可续接，分叉节点只移除关联线；局部剪贴板不要求选中起止，重建节点、作用域和边 ID，保留边位。排列使用邻接索引，符号候选只采用确定的执行前缀。

运行要求有效入口、节点可达与普通路径到达结束，控制转移保持既有语义。所有作用域及被调用工作流的多出口在准备阶段返回定位诊断并阻止执行；条件连线配置和分支执行尚未实现。结构化 If、Switch、While、ForEach 保持原执行行为。

## 绘制与验证边界

派生场景以不可变文件快照作为弱缓存键；平移、缩放和选择不重算连线路由。主表面按设备像素比设置缓冲区，缓存文字测量和图标，裁剪视口外内容，通过 requestAnimationFrame 合并更新，静止时不循环绘制。字体、主题和 DPI 变化会使相关绘制状态失效；卸载清理帧请求、图标回调和事件订阅。

路由内核按四边法线出入，先尝试有效简单正交路线，再按距离和转弯代价搜索障碍可见网格。相向、对齐且无遮挡的端口直接连线；错开的相向端口按净间距共享出入引线空间，避免短间距时引线交错产生回环。障碍包含同层节点、起止卡片与无关容器，间距为 12 个画布单位；允许线条相交。圆角半径默认 10，短段和窄通道缩小圆角，实际圆弧再次检查碰撞。重叠或搜索预算耗尽时返回受阻状态，绘制为警示虚线。绘制、方向箭头和命中共用直线与真实圆弧几何。

局部缩放小于 100% 时，线宽、箭头、悬停与选中底衬、虚线间隔随节点等比缩小；放大到 100% 以上时保持其屏幕尺寸，避免过粗。已有线路和拖拽预览共用此规则。端点操作点及命中容差继续按屏幕像素计算，使缩小后的细线仍可选中和操作。

新建、改接与节点移动共享路由器。节点移动预览按旧、新障碍包围盒更新受影响线路，包括未连接到该节点的线；取消不改文件。连线手势仅更新绘图预览，按帧消费最后一次指针位置，不逐事件写入 React 或工作台文件状态。

平移手势通过独立相机预览直接通知绘图表面，不在每次指针移动时刷新工作台状态，也不读取 DOM 布局或执行命中检测。松手将最终位置一次写入 `EditorTab.viewport`，取消丢弃预览；外部定位接管相机后，旧手势不能覆盖新位置。高频事件测试验证 100 次移动合并为一帧、拖动期间零工作台状态通知，以及松手、取消、只读浏览与卸载行为。

交互测试位于 `tests/frontend/workflow/canvas/`，图契约与几何测试位于 `tests/frontend/workflow/edge-*.test.ts`，覆盖四边路由、曲线命中、改接、保存、复制和取消。Rust 的保存与执行测试位于根目录 `tests/argusflow-desktop/`、`tests/argusflow-runtime/`。千节点用例检查可见区域裁剪与路径复用；它不代表真实 WebView 的帧率保证。jsdom 的绘图上下文替身不用于宣称像素或浏览器视觉验收通过。
