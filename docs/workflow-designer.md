# Workflow 设计器

## 启动

当前桌面工作台面向 Windows x64，使用 Tauri 2、React、Tailwind 和 Monaco。需要 Rust MSVC 工具链、Node.js、pnpm，以及 WebView2。AQL WASM 的工具链安装步骤见 [AQL 说明](aql.md)。

```powershell
pnpm install --frozen-lockfile
pnpm start
```

`pnpm start` 同时启动 Vite 与 Tauri；单独 `pnpm dev` 只提供网页资源，文件读写、能力装配和工作流运行依赖桌面宿主。

```powershell
pnpm tauri build --no-bundle
```

构建会先执行 WASM、TypeScript 检查和前端生产构建，再生成 `target/release/argusflow.exe`。当前不生成安装包。

## 从第一个流程开始

1. 启动后自动准备本机工作流数据，无需选择目录；加载失败时按提示处理后点击“重试”。
2. 新建空工作流，或选择“循环与变量”模板。循环模板依次累计 1、2、3，输出 `total = 6`，无需外部资源。
3. 点击或拖入节点；也可在画布按 Tab 搜索、双击空白、右键添加、拖线到空白后添加，或在线路上插入。
4. 选择节点，在右侧直接编辑标题和主要参数。“执行设置”和“备注”默认折叠；较长的 AQL 放到底部编辑。
5. 点击“校验”，根据“问题”面板定位节点。未完成的字段会阻止运行。
6. 点击“运行”；有根输入时先填写参数。底部日志显示执行过程，“输入输出”显示本次最终输出。

浏览器模板会创建浏览器、页面和 DOM 查询来源，需要先配置浏览器程序路径、网址和目标 AQL。模板不会自动寻找或接管用户已有浏览器。

## 画布与配置

循环、条件和步骤分组拥有内部作用域。放大指针所在容器可进入内部，缩小可返回；双击和面包屑也可导航。进入阈值为内部有效缩放 0.8，退出为 0.6，切换保持视口连续。独立 workflow 调用通过标签页打开目标文件。

根画布不重复显示工作流名称，进入子作用域后才显示层级导航。画布右上角提供两组紧凑图标：选择／平移、居中显示／显示全部／小地图。居中显示优先定位选中节点并保持缩放，显示全部适配当前作用域；滚轮继续负责缩放，不显示百分比与加减按钮。

右键菜单使用 28px 行高、图标和细分隔线。“添加节点”的二级菜单可直接插入常用节点，并提供完整节点库搜索；“排列与对齐”的二级菜单提供六向对齐、水平／垂直分布及整理当前作用域。子菜单支持悬停、点击及右方向键展开，左方向键或 Escape 返回上级，靠近窗口边缘时自动避让。

连线仅在同一作用域内连接，不允许用回边表达循环；循环使用对应容器。开始和结束是作用域边界，不额外创建执行节点。空作用域只显示添加首个节点的引导；有节点时使用图标与文字并排的紧凑起止卡片，通过侧边端口拖线连接。开始对齐实际入口节点的中心，结束对齐自然出口中心范围的中点；作用域边界预留卡片与连线空间，起止连线复用节点路由。

多选支持一起拖动、对齐和分布。容器复制包含内部节点，重新分配节点和作用域 ID，并重写内部引用。跨流程复制不会把失效引用自动连接到同名对象；这些引用会标记为待配置。

参数支持固定值、引用值和表达式。引用候选按作用域与类型过滤；页面、窗口和查询来源通过资源端口显式绑定。

| 快捷键                         | 操作                     |
| ------------------------------ | ------------------------ |
| Tab                            | 搜索并添加节点           |
| Ctrl+C / Ctrl+X / Ctrl+V       | 复制、剪切、粘贴         |
| Ctrl+D                         | 创建副本                 |
| Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y | 撤销、重做               |
| Ctrl+A / Delete                | 当前作用域全选、删除     |
| Ctrl+S                         | 立即保存                 |
| F2 / Enter                     | 重命名、配置或进入结构   |
| 空格拖动 / 中键拖动            | 平移                     |
| 滚轮                           | 缩放                     |
| 方向键 / Shift+方向键          | 微调节点                 |
| Esc                            | 取消菜单、连线或当前拖动 |

输入框、Monaco、文本选区和输入法组合输入保留原生键盘操作。粘贴使用最近的画布指针位置；没有指针位置时使用视口中心。

## AQL 与草稿

在节点“目标查询”中点击“编辑”进入底部编辑区。中文语法检查通过后，点击“应用查询”，由 Rust 节点编译器解析实际参数端口并保存英文查询。重新打开编辑区会恢复已保存参数。

查询、参数变更和已删除参数的草稿清理属于同一次撤销事务。新的输入、撤销、标签切换或其他配置修改会阻止旧异步结果覆盖当前草稿；保留的参数和其他字段的未完成原文不会被清除。

## 文件与自动保存

工作流固定存储在 `%APPDATA%\com.argusflow.desktop\workflows`，由 Tauri `app_data_dir()` 解析持久应用数据目录，首次运行自动创建并检查写权限。该位置不作为缓存或临时目录使用，但无法阻止第三方软件主动删除文件。旧的用户自选目录不会自动迁移，旧路径偏好也不再读取。

每份文件为 `<稳定ID>.workflow.json`，包含当前领域定义、节点布局和字段草稿。重命名显示名称不会改变调用引用。数据目录内只读取此格式；不导入 experimental 的旧协议。空目录显示欢迎页；已有文档时自动打开按名称排序的首份流程。

修改后约 800ms 自动保存；Ctrl+S 和运行前会等待已打开文档保存完成。保存采用临时文件、同步写入及原子替换，使用内容修订值检测外部修改。

发生冲突后停止覆盖磁盘文件：

- “保留为副本”用新 ID 保留当前草稿，并移除原冲突标签；原磁盘文件保持其外部版本。
- “重新载入磁盘版本”放弃当前标签的编辑内容，载入磁盘版本。

关闭窗口先保存；保存失败会保留窗口和草稿。

## 独立 workflow 与执行

“调用工作流”引用本机数据目录的另一份文档，按目标声明配置输入和借用资源。目标可单独运行，也可在调用中返回其声明的输出。独立 workflow 的全局变量相互隔离，数据通过显式参数传递。

运行开始前冻结根文档及全部可达依赖；缺失文档、递归、端口错误和未完成草稿会阻止执行。一次运行最多包含 256 份依赖文档，调用深度上限为 64。

一个工作台同时只运行一个根流程。运行与收尾期间，执行快照涉及的文档只读；取消、总预算及资源管理覆盖整个调用链。点击“停止”请求协作取消，等收尾结束后发布最终结果。

日志、订阅快照和最终状态使用同一有序通道。最终状态在事件消费完成、输出和错误就绪后发布，宿主保留最近 5000 条日志，截断和事件缺口显式展示。页面订阅断开不丢失运行句柄或最终结果；运行失败时自动展开日志，可按级别筛选、复制、导出和定位节点。

关闭时等待活动运行最多 15 秒；超时会保留窗口和句柄，允许稍后重试。活动运行结束后，再进行引擎保留资源和共享服务的有界清理。该等待上限不意味着强制终止阻塞的原生调用。

## 布局与主题

工作台以画布为中心，左侧为流程和节点，右侧为当前配置，底部为日志、问题、输入输出或 AQL。左右面板可折叠和调整，底部可收起或放大；界面偏好独立于流程文件保存。

40px 标题栏保留应用标识、工作流标签和窗口操作。标签横向滚动并保留窗口拖动区；新建入口位于欢迎页及左侧“流程”视图，标题栏不放“＋”。撤销／重做、保存状态、校验和运行放在画布上方的独立操作栏，仅打开工作流时显示。底部状态栏集中面板开关与主题选择；属性面板开关和画布快捷键提示仅在编辑工作流时显示，隐藏面板后仍可从状态栏恢复。窗口关闭按钮平时为中性色，悬停时显示红底白叉。滚动区域统一使用随主题变化的细滑块和透明轨道，隐藏两端箭头，仅在内容溢出时出现。

左侧通过 28px 的流程／节点入口切换，默认显示节点树。分类行高 24px，节点行高 28px；方向键导航与折叠，Enter 添加，节点描述在悬停时显示。搜索临时展开匹配分类，清空后恢复折叠状态。

常用组按成功添加次数排序，同次数按最近添加排序，最多显示八项；无统计时提供推荐节点。拖放和搜索插入同样计数，撤销重做、复制粘贴不计数。常用统计作为本地界面偏好保存，不读取旧收藏记录。

所有基础表单控件从 `components/ui` 复用；控件契约及使用示例见 [UI 基础组件](ui-components.md)。

属性面板采用以主要配置为中心的布局：标题直接编辑、短参数按内容占宽、AQL 集中展示、次要设置折叠。设计参考位于 `docs/design/workflow-inspector-light.png` 和 `workflow-inspector-dark.png`。

`src/features/themes` 定义强类型主题和注册表，内置浅色、深色及跟随系统。组件、SVG 与 Monaco 通过语义颜色同步切换。扩展主题只需提供完整主题定义并注册，不在业务组件中添加主题分支。

## 当前边界

首版不提供断点、暂停、单步、变量调试器、异常捕获或自动重试编排入口；Rust 引擎已有能力仍保留。根资源端口供跨工作流借用，工作台独立运行时需要通过流程节点创建实际资源。

本次未执行浏览器自动化、真实桌面键鼠、GPU 或 OCR 验收。非浏览器组件测试和后端测试的具体范围见 [验证记录](workflow-designer-validation.md)，不能代替真实视觉或平台交互验证。
