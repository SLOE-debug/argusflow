# ArgusFlow 初始架构

ArgusFlow 只面向 64 位 Windows。项目将领域契约、工作流执行、动作路由、Windows 自动化后端和 Tauri 界面分开；`src-tauri` 只负责进程入口、IPC 与事件桥接，自动化实现不会堆进入口文件。

这里的“后端”表示 Windows 应用内部的自动化路径，不表示操作系统平台：CDP 只面向 Windows 上的 Chrome、Edge 和 Chromium，视觉模块只接 Windows 的 DXGI/WGC 截图链路。

```text
React workflow editor
        │ Tauri IPC
        ▼
argusflow-runtime ──► argusflow-agent
                          │
              ┌───────────┼───────────┐
              ▼           ▼           ▼
          Windows UIA   Browser CDP   Vision/OCR
```

动作后端的预定顺序是 UIA、CDP、视觉缓存、OCR tiny、OCR medium、GUI grounding、SendInput。当前仅实现接口和未接入错误，演示工作流只执行 Log 与 Delay 节点。
